Project: Client Snapshot, a planning tool for advisors

I came up with and directed the creation of a free tool that financial advisors can use in a client meeting. The advisor enters a client’s fact-finder numbers and gets a one-page analysis they can print or save as a PDF.

  • Life insurance needs using the DIME method (Debt, Income, Mortgage, Education), compared with coverage already in force
  • Retirement readiness in today’s dollars, with what-if sliders and side-by-side scenarios
  • Debt payoff and college funding comparisons

I built it with AI assistance (Claude by Anthropic). All calculations run in the browser, so no client data is stored or sent anywhere. It is an illustration, not financial advice.
